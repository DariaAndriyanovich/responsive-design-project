# 🌿 Responsive Design Project

This is a responsive HTML & CSS website about Estonian bogs (*rabad*), showcasing a nature-themed layout with image galleries and structured sections.

## 🔗 Live Demo  
👉 [Open the site](https://dariaandriyanovich.github.io/responsive-design-project/)

---

## 🌟 Features  
- Fully responsive layout using CSS flexbox  
- Nature-themed image gallery  
- Clear structure with HTML5 semantic elements  
- Clean and simple visual design  

---

## 🛠️ Technologies Used  
- HTML5  
- CSS3  
- Visual Studio Code
